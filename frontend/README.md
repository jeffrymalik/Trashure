# Trashure Frontend

Aplikasi web frontend untuk Trashure, dibangun dengan Next.js 16.

## Persiapan

- Node.js 18+

## Instalasi

```bash
npm install
```

## Menjalankan

```bash
npm run dev
```

Buka http://localhost:3000 di browser.

## Perintah Lain

```bash
npm run build   # Build untuk produksi
npm start       # Jalankan versi produksi
npm run lint    # Jalankan ESLint
```

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Lucide React (ikon)
